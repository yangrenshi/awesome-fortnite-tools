# Awesome Fortnite Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of practical Fortnite companion tools, trackers, odds helpers, and map resources for Battle Royale players.

Focus: free or freemium web tools that help players during matches or season events — without requiring shady account linking when possible.

## Companion Counters & Odds

- [TrackChest](https://trackchest.com) - Fast, zero-login companion counter to log opened chests and model Pirate Token odds during Fortnite Chapter 7 Treasure Hunters.
- [Fortnite.gg](https://fortnite.gg/) - Live map, item shop, and player-facing Fortnite data tools.

## Stats Trackers

- [Fortnite Tracker](https://fortnitetracker.com/) - Match history, lifetime stats, and leaderboards.
- [FortniteDB](https://fortnitedb.com/) - Items, cosmetics, and stats database.

## Item Shop & Cosmetics

- [FNBR.co](https://fnbr.co/) - Item shop tracker and cosmetic catalog.
- [FortniteAPI.io](https://fortniteapi.io/) - Shop, stats, and cosmetics API with docs.

## Maps & Drop Routes

- [Fortnite Creative Discover](https://www.epicgames.com/fortnite/creative/discover) - Official Creative map discovery.
- [Fortnite Wiki](https://fortnite.fandom.com/) - Community wiki for POIs, items, and season mechanics.

## APIs & Developer Resources

- [Epic Games Developer Portal](https://dev.epicgames.com/) - Official Epic developer resources.
- [fortnite-api.com](https://fortnite-api.com) - Community Fortnite API.
- [fnbr.js](https://github.com/fnbrjs/fnbr.js/) - JavaScript library for Fortnite client services.

- [r/FortniteCompetitive](https://www.reddit.com/r/FortniteCompetitive/) - Competitive Fortnite discussion.

## Contributing

PRs welcome. Please:

1. Keep entries alphabetical within a section when practical.
2. Prefer free / no-login tools that help real players.
3. Use the format: `- [Name](https://example.com) - Short description.`
4. Do not submit malware, account sellers, or ToS-breaking clients.
